# Modules

The application is organised as one controller per business module. Most modules
are **CRUD screens generated by Grocery CRUD** (`set_theme(...)` selects the
table UI); a few are **custom screens** (invoices, salary slips, reports).

![Module map](assets/modules.svg)

## Controllers

| Controller | Type | Theme / view | Purpose |
|---|---|---|---|
| `Welcome` | custom | `welcome_message` | Framework default landing route. |
| `User_Authentication` | custom | `login_form`, `admin_page` | Login, logout, dashboard. |
| `Accounts` | CRUD | bootstrap | Chart of accounts / parties (clients, vendors, owners, cash). |
| `Arabic_description` | CRUD | bootstrap | English ⇄ Arabic description lookup. |
| `Employees_data` | CRUD | bootstrap | Employee records and documents. |
| `Expenses` | CRUD | flexigrid | Expense entries per account. |
| `Investments` | CRUD | flexigrid | Investment / equity entries. |
| `Transactions` | CRUD | flexigrid | Account-to-account transactions. |
| `Owner_transactions` | CRUD | datatables | Transactions scoped to owner accounts. |
| `Profits` | CRUD | datatables | Profit entries per owner account. |
| `Vehicles_data` | CRUD | bootstrap | Vehicles and their documents. |
| `Rental_equipments` | CRUD | bootstrap | Rental equipment per order/vendor. |
| `Trips` | CRUD | bootstrap | Trip/callout records. |
| `Orders` | CRUD | bootstrap | Client orders. |
| `Order_items` | CRUD | bootstrap | Line items within orders. |
| `Vendor_contracts` | CRUD | bootstrap | Vendor contracts. |
| `Vendor_items` | CRUD | bootstrap | Items under vendor contracts. |
| `Upload_invoices` | CRUD | bootstrap | Invoice file uploads. |
| `Invoice` | custom | `invoice_view` | Printable client invoice. |
| `Vat_invoice` | custom | `vat_invoice_view` | VAT-compliant invoice. |
| `Vat_invoice_1` | custom | `vat_invoice_view_1` | Alternate VAT invoice layout. |
| `Salary_slip` | custom | `salary_view` | Printable salary slip. |
| `Data_reports` | custom | `data_reports_view` | Operational reports. |
| `Get_report` | custom | `report_view` | Financial reports incl. income statement and expense sheets. |
| `Vendors_multigrid-nill` | legacy | — | Unreachable variant: filename contains a hyphen (class is `Vendors_multigrid`). Retained for reference. |

## Reports (`Get_report`)

The reporting controller exposes several named reports, each with a data-fetch
pair and a printable sheet:

| Report | Handler | Data |
|---|---|---|
| Vendor trips | `vendor_trips_report` | `get_report_form`, `get_duration_form` |
| Vendor equipment | `vendor_equipments_report` | duration form |
| General expenses | `general_expenses_report` | `get_general_expenses` |
| Vehicle expenses | `vehicle_expenses_report` | `get_vehicle_expenses` |
| Expenses sheet | `show_expenses_sheet` | `get_expenses_sheet` |
| Income statement | `show_income_statement` | `get_income_statement` |
| Transactions | `transactions_report` | `get_monthly_transactions` |
| Vendor contracts | `vendor_contracts` | `get_vendor_contracts` |
