# admin_resources/

The admin front-end theme: **Start Bootstrap SB Admin 2** (Bootstrap 3 line),
plus jQuery 3.5.1.

| Path | Contents |
|---|---|
| `vendor/bootstrap/` | Bootstrap 3 CSS/JS |
| `vendor/jquery/` | jQuery (incl. `jquery-3.5.1.min.js`, used by `admin-js.php`) |
| `vendor/font-awesome/` | Icon font |
| `vendor/metisMenu/` | Collapsible menu plugin |
| `vendor/morrisjs/`, `vendor/raphael/` | Charts (CSS/JS loaded on demand) |
| `dist/css/sb-admin-2.css`, `dist/js/sb-admin-2.js` | Theme styles/scripts |
| `data/morris-data.js` | Sample chart data |
| `LICENSE` | SB Admin 2 MIT licence |
